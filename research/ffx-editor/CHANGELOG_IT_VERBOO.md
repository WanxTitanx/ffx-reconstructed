# Changelog

Questo file registra l'evoluzione ufficiale di `FFX Project Editor` e dell'ecosistema dei laboratori `Pt`.

Copre tre livelli di cronologia:

- release e baseline della `main`;
- milestone semantici ricostruiti della `main` nel periodo pre-Git ufficiale;
- mini-versioni editoriali e snapshot di conoscenza dei laboratori `Pt2` a `Pt45`.

Regole di questo changelog:

- **regola vigente (dal 2026-06-04, vedi `docs/governance/VERSIONING.md` sec. 4):** ogni aggiunta **shippabile** (writer, modulo, prova, capacità, doc-di-registrazione) prevede un bump nei 4 campi del `FFXProjectEditor.csproj` + voce qui **e** in `changelogUS.md` + riga in `VERSIONING.md`;
- classifica ogni voce: **MINOR** / **PATCH** / **REVISION**; firma con lane (`Jarvis-ARENA`, `Jarvis-MAGIC`, ecc.) quando multi-chat;
- mantieni la catena `[anterior: vX.Y.Z.W]` lineare — senza saltare numeri;
- **nessun bump** solo per trivial (typo, spaziatura, rinomina interna, refactor byte-identico senza fix);
- registra anche traguardi, assorbimenti, freeze, blocchi e handoff;
- non fingere una cronologia Git antica che non è mai esistita;
- quando una versione semantica antica è stata ricostruita editorialmente, contrassegnala come `historical reconstruction`;
- quando un laboratorio modifica molto il progetto ma non entra nella `main`, appare qui come modifica dell'ecosistema, non come feature già portata.
