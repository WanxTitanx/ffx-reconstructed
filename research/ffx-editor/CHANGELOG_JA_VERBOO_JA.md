# チェンジログ

このファイルは `FFX Project Editor` および `Pt` エコシステムの公式な進化を記録します。

3つの履歴レベルを網羅します：

- `main` のリリースおよびベースライン；
- Git公式導入前の `main` の再構築されたセマンティックマイルストーン；
- `Pt2` ～ `Pt45` のワークショップにおけるミニバージョンエディションおよびナレッジスナップショット。

このチェンジログのルール：

- **現在有効なルール（2026-06-04以降、`docs/governance/VERSIONING.md` 第4節参照）：** すべての **出荷可能** な追加（ライター、モジュール、テスト、機能、登録ドキュメント）は `FFXProjectEditor.csproj` の4フィールドをバンプし、ここで**かつ** `changelogUS.md` にエントリを追加し、`VERSIONING.md` にラインを記録；
- 各エントリは **MINOR** / **PATCH** / **REVISION** で分類し、マルチチャット時はレーン（`Jarvis-ARENA`、`Jarvis-MAGIC` 等）で署名；
- `[anterior: vX.Y.Z.W]` の連鎖を線形に維持 —— 番号をスキップしない；
- **バンプしないのは** トライビアル（タイプミス、ホワイトスペース、内部リネーム、修正なしのバイト同一リファクタリング）のみ；
- マイルストーン、統合、フリーズ、ブロック、ハンドオフも記録；
- 存在したことのない古いGit履歴を偽造しない；
- 古いセマンティックバージョンがエディションで再構築された場合は `historical reconstruction` とマーク；
- ワーッシュップがプロジェクトを大きく変更するが `main` に含まれない場合は、ここにエコシステムの変更として記載し、移植済み機能として記載しない。
